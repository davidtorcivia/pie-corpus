## 1. Neuter s-stems

**Right** (against Ringe 2006 §2.3.4(iii) pp. 48–49, paradigm *nébʰos*; Fortson §6.38; Beekes 13.2.6c pp. 204–205):
- root accent and full grade throughout, suffix *-os* (direct) / *-es-* (oblique): ḱléwos, gen. ḱléwesos, dat. ḱléwesey, loc. ḱléwesi/ḱléwes, ins. ḱléwesh₁ (Ringe nébʰesos, nébʰesey, nébʰes(i), nébʰes(e)h₁).
- dual nom.-acc. *-es-ih₁* (ḱléwesih₁; Ringe nébʰesih₁; Fortson §6.13 Ved. rájas-ī).
- loc. pl. *ḱléwesu*, with *-s-su* simplified: Ringe writes nébʰesu, and Fortson §3.37 has *ss* → *s* at morpheme boundaries. So the degemination in `join` is right here.
- ins. pl. -esbʰis, d.-abl. pl. -esbʰos/-esmos, gen. pl. -esōm/-esoHom.

**Handbooks disagree (no change):**
- nom.-acc. pl. The engine has *-es-h₂* primary and the collective *-ōs* as alternative (ḱléwesh₂ / ḱléwōs). Beekes 13.2.6c and Fortson §6.15 (Hom. géne-a) support *-esh₂*. Ringe's paradigm writes *nébʰōs*. The current order is a deliberate t019-review choice, and Beekes and Fortson support it, so keep it.
- gen. sg. accent. Beekes writes PD *-és-os*. Ringe and L&Y (Handbook v3 ch. 122, *ǵénh₁-es-e/os*, root accent) keep root accent, and the engine follows Ringe. Keep it.

**Wrong:** F3 (accentless headwords under the shape rule): Hrewdos, h₁rowdʰos, leh₂dʰos, medos, moyth₂os, stugos (ḱh₂dos has no root vowel at all; the lexicon form should be *ḱéh₂dos*, Gk κῆδος, which is a lexicon gap and not something the engine can fix).

## 2. Animate s-stems

**h₂éwsōs** (233 tokens). It matches Fortson §6.24 in nom. *h₂éwsōs*, acc. *h₂éwsosm̥* and voc. *h₂éwsos*. Fortson writes gen. *h₂us-s-és*, Beekes 13.2.5g (p. 198) *h₂us-s-ós*, and the engine (from Wiktionary) has *h₂usés*. By Fortson's own §3.37 (*ss* → *s* at a morpheme boundary), the surface form is *h₂usés*, so this is not a defect. The obliques (dat. h₂uséy, loc. h₂usési/h₂usés, loc. pl. h₂usú) are consistent with that.

**-ēs bahuvrīhis** (pie/compound.py). Cells: m./f. nom. *-ēs*, acc. *-esm̥*, gen. *-esos*, nom. pl. *-eses*, neuter *-es* with pl. *-esh₂ / -ēs*. These match the Greek and Vedic reflexes the module cites, and the common gender is right. Accent: the engine applies the BAP (h₁suḱléwēs, dusménēs, with the oxytone *h₁suḱlewḗs* as alternative). Fortson §6.39 and Beekes (*h₁su-men-ḗs*, 13.2.5g) write the derivative suffix accented. L&Y (Handbook v3 ch. 122, BAP section) give Ved. suśrávas-. This is a documented convention in compound.py, so it is marked as a disagreement only.

**Comparatives** (méǵyōs, pléh₁yōs, swéh₂dyōs). The engine copies Wiktionary's acrostatic table (gen. *méǵh₂isos*). Fortson §6.78 calls the suffix amphikinetic (weak *-is-*), and Beekes 13.2.5g (p. 198) writes gen. *-is-ós*. No weak-case tokens are in the corpus. If the project wants to follow the handbooks, the override is `{"id": "pie-lex-megjyoxs", "spec": {"m_weak": "meǵh₂is"}}`, and the same for the other two, which gives gen. *meǵh₂isés* (*-ós* as alternative). This is optional.

**dusmenēs** (noun lexeme): F10.

- *wréh₂ds*, *h₂stḗr*: match Ringe.
- *dṓm*: nom. dṓm, gen. *déms* (Fortson §6.25, Ringe p. 44, Beekes 13.2.8a).

- F6 *dʰǵʰúHs*, F4 *h₃ókʷs*, F5 *dóws*.
- F9 voc. *ǵʰh₂ens*.

- *ḱwṓ* loc.: Ringe *ḱwón(i)*, Wiktionary and the engine *ḱwén(i)*.

## 4. r/n and l/n heteroclites

**Right:**
- acrostatic *wódr̥ ~ wédn̥s* (Fortson §6.31: *u̯ód-r̥, u̯éd-n-*, Hitt. wātar/witenaš).
- proterokinetic *péh₂wr̥ ~ ph₂wéns*, *sóh₂wl̥ ~ sh₂wéns* (Fortson §6.22, Ringe pp. 45 and 47: sh₂wénh₁, sh₂wéney, sh₂wéns, sh₂wén(i); Beekes 13.2.6e *péh₂-ur, p(e)h₂-uén-s*, *séh₂-ul, sh₂-uén-s*).
- *h₁ésh₂r̥ ~ h₁sh₂én-* (Beekes 13.2.6e).
- dual: strong stem + *ih₁* (wódrih₁), on the pattern of Ringe's neuters ḱérdih₁ and dórwih₁.
- the oblique plurals on the singular weak stem (wédn̥bʰos, wédn̥su). These are not in the handbooks. The Wiktionary collective oblique (*udnés*, coll2 *udn̥*) is the collective's singular, not a plural. Keep them.

**Handbooks disagree:** *wódr̥*'s oblique. Fortson has acrostatic *wéd-n-*, which the engine follows. Ringe (p. 45) and Wiktionary's second table have proterokinetic *udén-*. Keep it.

**Wrong:**
- F1, the collective. Fortson §6.15 (*ud-or-h₂* > *ud-ōr*, Hitt. widār), Ringe p. 45 (*wédōr ~ udn-ʹ*, amphikinetic collective) and Wiktionary's `coll=` arg on 18 of the 22 tables (wédor, déh₃or, h₂égor, péh₂wor, yékʷor …) all have the collective *CéC-ōr*. The engine's neuter-plural branch builds the lengthened collective only when the stem ends in a non-syllabic *s/n/r*. Every heteroclite ends in syllabic *r̥/l̥*, so it falls through to *strong + h₂*. The root cause is upstream: `spec_from_template` drops the `coll`/`coll2`/`coll_loc` args.
- F2 *yókʷr̥*. Ringe p. 44 has *Hyḗkʷr̥ ~ Hyékʷn-*, Fortson §6.21 *i̯ḗkʷ-r̥* (Av. yākarə, Gk ἧπαρ), Beekes 13.2.6e *iékʷ-r*. Ved. yákr̥t, with short *a* in an open syllable, rules out *o* (Brugmann). Wiktionary itself carries a second, proterokinetic *yékʷr̥* table.

## Proposed fixes (in impact order)

### F1. Heteroclite collective *-ōr* (pie/morph.py)

The rule below reproduces Wiktionary's `coll=` arg on 17 of the 18 tables that carry one (wódr̥ → wédōr, yókʷr̥ → yékʷōr, dóh₃r̥ → déh₃ōr …). For the 4 lexemes without one it gives sóh₂wl̥ → séh₂wōl, h₁ówHdʰr̥ → h₁éwHdʰōr, snéh₁wr̥ → snéh₁wōr and pérwr̥-2 → pérwōr; these are lower-confidence. The exception is *sóḱr̥*, where Wiktionary has *sḱór* and the rule gives *séḱōr*. That lexeme has 1 token (NOM.SG, unaffected). It is self-contained: no spec change is needed.

```diff
--- a/pie/morph.py
+++ b/pie/morph.py
@@ def _athematic(spec: NounSpec, conv: str) -> Cells:
     if neuter:
         if len(strong) > 1 and strong[-1].base in ("s", "n", "r") and not strong[-1].syl and strong[-2].kind == "V":
             # collective: -os-h₂ → -ōs, -or-h₂ → -ōr, -on-h₂ → -ō
             coll = lengthen_last_vowel(strong if strong[-1].base == "s" else strong[:-1])
             npl = [render(coll)]
             if hb and strong[-1].base == "s" and e_grade_s and spec.weak:
                 # s-stem neuters: handbook *-es-h₂ (Fortson; Gk γένεα, Ved. -āṃsi, Lat. genera), the
                 # collective -ōs kept as the alternative (t019 review: nébʰōs read as a plural)
                 npl = [render(_add(weak, "h₂"))] + npl
+        elif hb and len(strong) > 2 and strong[-1].kind == "R" and strong[-1].syl and strong[-1].base in ("r", "l") \
+                and any(x.acc and x.kind == "V" for x in strong):
+            # r/n (l/n) heteroclite: collective *CéC-ōr < *-or-h₂ (Fortson §6.15 *ud-ōr, Hitt. widār; Ringe 2006
+            # §2.3.4(ii) *wédōr; Wiktionary coll= wédor, péh₂wor, déh₃or, yékʷor): accented e-grade root,
+            # lengthened -ōr/-ōl. The pre-form *-r̥-h₂ stays as the alternative.
+            i = next(j for j, x in enumerate(strong) if x.acc and x.kind == "V")
+            root = strong[:i] + [Seg("e", "V", acc=True)] + strong[i + 1:-1]
+            npl = [render(root + [Seg("o", "V", long=True), Seg(strong[-1].base, "R")]), render(_add(strong, "h₂"))]
         else:
             npl = [render(_add(strong, "h₂"))]
```
