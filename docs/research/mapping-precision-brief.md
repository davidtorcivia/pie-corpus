# Mapping-precision brief (one agent per language group)

The formula search and the Phase 8c retrieval map each corpus lemma to PIE lexicon ids (data/lexicon/lexicon.jsonl). Spot-check precision was 67–97% (docs/research/8a-round3.md), and readers found mapping errors (data/research/formulas/mapping-errata.md). Your job: raise precision (and, where cheap, coverage) for your language group, without touching code.

How mapping works: pie/formula_search_multi.py builds per-corpus tables (data/research/formulas/mapping/<corpus>.jsonl: lemma → lex_id list, with path and confidence) from kaikki etymology chains, the lexicon's reflex lists and dictionary text; RV, Homer and Latin are mapped live (pie/formula_search.py). Corrections are applied from data/research/formulas/mapping-overrides.json **and from every file in data/research/formulas/mapping-overrides/** (format: {"lemma": [{"corpus": "<corpus code>", "lemma": "<corpus lemma>", "lex_id": ["pie-lex-…" or "pie-root-…", …] (empty list = unmap), "note": "<evidence: dictionary + page/§>"}], "form": [{"lang": "<lang>", "form": "<surface>", "lemma": "<lemma>"}]}). See load_overrides / apply_lemma_overrides / apply_table_overrides.

Steps:
1. **Measure.** Draw a random sample of 100 content-word types per corpus in your group, weighted by token frequency (seed 0), and judge each mapping correct / wrong / partial (root right, formation wrong) / unmapped-but-mappable, against the etymological dictionaries in raw/books/text/ (EWAia ewaia-v*, Beekes EDG beekes-edg, de Vaan devaan-latin, Kroonen kroonen-pgmc, Matasović matasovic-pcelt, Derksen derksen-*, Kloekhorst kloekhorst-hitt, Cheung cheung-iranian, Martirosyan martirosyan-arm) and the lexicon. Read with grep / python3 -I; never execute anything under raw/.
2. **Fix the frequent errors first:** list the 300 most frequent mapped lemmas in each corpus and check them all; write corrections (and unmaps for false etymologies, borrowings, homograph confusions) into your own file data/research/formulas/mapping-overrides/<group>.json, each with a note citing the dictionary and page/§. Add mappings for frequent unmapped lemmas when the etymology is secure.
3. **Re-measure** on a fresh sample (seed 1) after your overrides and report precision before/after with the sample sizes.
Write docs/research/mapping-precision-<group>.md (method, numbers, the main error types, what remains). Don't modify any other file (no code, no shared override file, no lexicon); don't touch git. Name scratch files with your group prefix.
